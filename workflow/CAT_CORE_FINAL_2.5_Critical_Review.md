# CAT CORE FINAL 2.5｜严重失误复盘与强制升级（2026-08-23）

**触发样本**：
- 赫尔城 2-0 曼联（预测客胜，实际主胜）
- 秋田 3-0 甲府（预测平/客，实际主胜大比分）

---

## 1. 赫尔城 vs 曼联 失败根因（必须正视）

**实际关键因素（赛后确认）**：
- 赫尔城门将 Tzolakis 表现极佳（多次关键扑救）
- 赫尔城采用极度密集防守 + 定位球高效
- 曼联物理对抗与第二落点全面落败
- 曼联21次射门仅0进球，终结效率崩溃
- 升班马主场能量 + 新援即战力被严重低估

**模型错误**：
- 过度依赖“曼联实力差”标签
- 完全没有评估“密集防守 + 优秀门将”组合对强队的克制
- 没有给升班马主场首战足够的战意与能量权重
- 比分习惯性给0-2/0-3，完全没考虑主队先制后的防守战剧本

---

## 2. 秋田 vs 甲府 失败根因

**实际关键因素**：
- 比赛有明显雨战影响
- 甲府进攻能力极弱，几乎无法创造威胁
- 秋田主场即使人员不整，仍能通过高强度和定位球打穿弱旅

**模型错误**：
- 伤停人数被过度放大，忽略了对手进攻端更差的事实
- 天气变量完全缺失
- 弱旅客场进攻能力评估不足

---

## 3. 强制新增模块（立即生效）

### 3.1 密集防守 + 优秀门将克制模块
当弱队/升班马主场采用低位密集防守，且门将质量高于平均时：
- 强队客胜概率必须下调
- 0-0 / 1-0 / 2-0（主队）进入比分池
- 强队射门转化率预期大幅降低

### 3.2 天气变量（雨战）
雨战必须检查：
- 技术型强队发挥下降
- 身体对抗与定位球权重上升
- 弱旅主场有时反而受益

### 3.3 升班马/弱旅主场首战能量
英超/五大联赛升班马主场首战，必须额外给予战意与主场能量加成，不能只看纸面实力。

### 3.4 比分幅度强制修正
- 禁止再默认只给0、1、2球思维
- 单边场景必须允许3-0、4-0、甚至更高
- 弱旅主场爆冷时，允许1-0、2-0作为首选

### 3.5 对手进攻真实威胁评估
不能只看自己伤停，必须同步评估对手能否真正创造机会。若对手进攻极弱，即使己方人员不整，主胜权重仍可保留。
