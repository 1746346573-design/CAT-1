# CAT CORE FINAL 2.0｜模型升级记录

**升级时间**：2026-08-13

---

## 1. 新增核心模块：PSI盘口冲突指数

**定义**：PSI（Price Sentiment Index / 盘口冲突指数）用于量化市场赔率/水位变化与球队真实实力、动机之间的冲突程度。

**计算逻辑（简化）**：
- 强队热门 + 盘口明显退让（水位向冷门方向移动）
- 同时出现小球倾向
- 市场资金高度集中在热门一侧
→ PSI 升高，触发冷门复核流程。

---

## 2. 核心推演流程升级

**旧流程**（偏重进球模型）：
实力 → xG/进球结构 → 比分

**新流程（CAT CORE FINAL 2.0）**：
1. **实力评估**（球队实力差距、排名、历史交锋）
2. **信息层**（阵容、伤停、动机、主客场、联赛特性）
3. **盘口层**（欧赔、亚盘、即时水位变化）
4. **PSI盘口冲突指数**（判断是否存在市场与实力冲突）
5. **比赛剧本**（主胜/平局/客胜/爆冷剧本）
6. **进球结构**（xG差值映射 + 联赛进球特征）
7. **最终比分池**（严格两个最可能比分）

---

## 3. 新增强制规则

**强队热门 + 盘口退让 + 小球倾向 + 市场集中 → 自动触发冷门复核**

触发条件同时满足时：
- 必须重新评估平局与客胜概率
- 高信心自动降级至少一级
- 比分池必须包含平局或冷门比分选项

---

## 4. 复盘样本（支撑本次升级）

| 比赛 | 赛前主流 | 实际结果 | 关键失败点 |
|------|----------|----------|--------------|
| 巴黎圣日耳曼 2:1 维拉 | 强队主胜 | 主胜但过程艰难 | 盘口退让信号被忽视 |
| 普拉滕斯 1:1 科金博联 | 主胜倾向 | 平局 | 小球 + 盘口冲突未识别 |
| 帕梅拉斯 1:1 波特诺 | 主胜热门 | 平局 | 强队热门被逼平，进球模型权重过高 |

**共性结论**：
单纯依赖进球/xG模型在“强队热门遭遇盘口退让 + 小球”场景下容易失效。  
必须提高**比赛场景识别**与**盘口冲突（PSI）**的权重。

---

## 5. 权重调整方向

- **降低**：单纯进球模型 / 纯xG映射权重
- **提高**：
  - 比赛场景与动机权重
  - 盘口冲突（PSI）识别权重
  - 平局反证权重（尤其在强队热门 + 盘口退让时）

---

## 6. 与现有模块的兼容

- 保留原有：杯赛追分修正、欧战主场热门反证、联赛动态权重、比分池强制两个
- 新增PSI作为独立检查层，插入在“盘口”与“比赛剧本”之间
- 积极模式继续，但高/中高信心必须通过PSI检查
