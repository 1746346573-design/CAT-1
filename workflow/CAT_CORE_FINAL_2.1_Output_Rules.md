# CAT CORE FINAL 2.1｜最终输出与决策规则（2026-08-20确认）

**状态**：正式锁定

---

## 1. 决策核心变更

- **砍掉动态联赛权重**
- 改为**交叉研判确认**机制
- **保留联赛数据库**（仅作为历史样本与基准参考，不做强制加减分）

### 交叉研判必须完成的检查项：
1. 实力差 vs 比赛目的（是否有理由全力踢）
2. 伤停位置 + 替补质量 vs 进攻兑现率
3. 盘口/资金 vs 剧本是否冲突
4. 历史同类场景（联赛数据库）vs 当前剧本
5. 大球类型拆分确认

任何一项出现明显矛盾 → 信心自动降级。

---

## 2. 强制输出格式（每场必须包含）

每场推演结果必须完整输出以下内容：

- **胜负平**（主胜 / 平 / 客胜）
- **让球胜负平**（根据主流让球盘）
- **半全场**
- **进球数**
- **三个比分**（按概率排序）

示例格式：

胜负平：主胜  
让球胜负平：让平 / 让胜  
半全场：胜胜 / 平胜  
进球数：2球 / 3球  
比分：2-0 / 1-0 / 2-1

---

## 3. 其他保留模块

- 核心问题（有没有理由按实力差全力踢）必须先问
- 伤停位置 + 替补质量
- 强队兑现率检查
- 机会制造 vs 机会转化拆分
- 大球强制拆分（单边/双边/碾压/后程开放）
- PSI仅作冲突预警
- 市场资金仅作异常校验
