# CAT CORE FINAL 2.4｜进球数 / 让球 / 半全场 深度研究补充（2026-08-22）

**基于周五8场真实赛果 + 全部赔率的继续研究**

---

## 1. 进球数（总进球）研究结论

### 样本表现
- 高进球场（4+球）：柏太阳神4-2、利雅胜利0-4 → 单边碾压型
- 中等进球场（2-3球）：东京2-0、阿森纳3-0、塞那乔其1-2
- 低进球场（0-1球）：胡拜尔0-1、贝蒂斯1-0
- 天狼星0-3 属于客队单边

### 关键发现
1. **单边碾压时，总进球容易超过模型预期**（4-2、0-4）
2. **中游主场热门被爆时，经常伴随小球或客队小胜**（0-1）
3. **强队主场对升班马/弱旅，3球是高频结果**（阿森纳3-0）
4. 北欧/芬超接近盘口时，2-3球仍是主流，但客胜时总进球不一定低

### 改进方向
- 单边碾压场景：总进球首选上调至3或3-4
- 中游主场过热被爆场景：优先考虑1-2球或小球
- 区分「对攻型大球」与「单边型大球」，后者更常见于强队取胜

---

## 2. 让球盘研究结论

### 样本表现
- 让一球主胜穿盘成功：东京FC（2-0）、阿森纳让两球打出
- 让一球主胜未穿 / 被爆：胡拜尔、天狼星、贝蒂斯（1-0只是让平）
- 客让球半/两球打出：利雅胜利0-4（+2让负成功）

### 关键发现
1. **让一球主胜的真实穿盘率被高估**，尤其在中游主场
2. **深让（让球半、让两球）在强队碾压时打出概率高于模型预期**
3. **让平成为“安全垫”的价值被低估**——很多主胜最终只是1-0、2-1
4. 机构大幅降低主胜赔率（向主队倾斜）时，让一球穿盘失败率明显上升

### 改进方向
- 中游主场让一球：默认优先「让平」，穿盘需要额外强证据
- 强队深让：允许让负（客队视角）或让平作为首选
- 过热主胜 + 让一球：强制降级为让平思维

---

## 3. 半全场研究结论

### 样本表现
- 胜-胜：柏太阳神、阿森纳、东京FC（平-胜）、贝蒂斯（平-胜）
- 负-负：利雅胜利、天狼星、胡拜尔
- 平-负：塞那乔其

### 关键发现
1. **强队主场对弱旅，胜-胜是最高频半全场**
2. **客队爆冷时，负-负（主队视角）或平-负较常见**
3. **平-胜出现在主队慢热或对手有抵抗的比赛**（东京、贝蒂斯）
4. 上半场0-0后主队取胜的情况不少，说明“上半场必须领先”不是必须条件

### 改进方向
- 强队碾压：优先胜-胜
- 中游主场热门：提高平-胜与平-平的权重
- 客队有爆冷可能时：负-负或平-负要进入前二

---

## 4. 综合行动项（已纳入模型）

1. 进球数：单边碾压上调，中游过热下调
2. 让球：中游让一球默认让平思维；深让强队允许更激进
3. 半全场：强队胜-胜，中游提高平-胜权重，爆冷场景加入负-负/平-负
4. 继续积累样本，动态验证以上规律
