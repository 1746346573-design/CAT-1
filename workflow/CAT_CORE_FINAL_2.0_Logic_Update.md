# CAT CORE FINAL 2.0｜逻辑升级补充（2026-08-13）

## 核心升级原则（必须执行）

1. **先问情境，再问实力**  
   不是“谁强就推谁赢”，而是先判断：  
   - 这场比赛双方有没有理由按照实力差全力踢？  
   - 是否存在晋级已定、首回合风险控制、尊严战、轮换动机等情境？

2. **比赛剧本优先级高于纯进球模型**  
   流程严格为：  
   实力 → 信息 → 盘口 → PSI → **比赛剧本** → 进球结构 → 比分

3. **特殊场景强制规则**  
   - **次回合且首回合分差≥3球**：强队动力下降，客胜/主胜方向保留，但大比分权重显著降低。  
   - **解放者杯/南美淘汰赛首回合**：双方风险控制优先，平局权重明显上调，小比分优先。  
   - **盘口平局被明显压缩（平赔≤2.80）且实力接近**：平局必须进入第一或第二推荐。

4. **比分池克制原则**  
   - 强队热门但情境不支持大胜时，优先 0-1 / 0-2 / 1-0 / 1-1，反对盲目 0-3 / 3-0。  
   - 首回合优先 0-0 / 1-0 / 1-1。

## 正式采纳的 008～010 标准逻辑

**008 哈茨 vs 本菲卡（次回合大比分领先）**  
- 方向：客胜（但非大胜）  
- 比分：0-2 > 1-2 > 1-1  
- 逻辑：晋级已定 → 强队控节奏 → 不追大胜

**009 米拉索尔 vs 基多体大（解放者首回合）**  
- 方向：主胜（小比分）  
- 比分：1-0 > 2-0 > 1-1  
- 逻辑：主场压迫 + 客队收缩 + 低比分胶着

**010 罗萨里奥 vs 科林蒂安（解放者首回合 + 盘口平局压缩）**  
- 方向：平为主，主胜为防  
- 比分：1-1 > 1-0 > 0-0  
- 逻辑：首回合 + 双方防守优先 + 实力接近 → 平局价值最高
