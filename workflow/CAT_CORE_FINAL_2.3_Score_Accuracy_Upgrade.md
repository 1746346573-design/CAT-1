# CAT CORE FINAL 2.3｜比分准确性提升 + 样本反馈与动态调整（2026-08-21）

**目标**：让比分预测更准确，同时建立可持续优化的闭环。

---

## 1. 当前比分准确性的主要瓶颈

从最近9场复盘看，方向命中率已达78%，但比分幅度仍有明显偏差（波兹南7-0、红星3-0、安德莱0-3等被低估）。

主要问题集中在：
- 强队单边碾压场景的识别不足
- 对手防线真实抗压能力评估不够
- 缺少「比赛打开后的进球加速度」判断

---

## 2. 需要重点加强的球队变量

### 2.1 高价值变量（优先加入）
1. **防线抗压指数**（对手被高位压迫时的失球频率）
2. **强队兑现率细分**：
   - 前30分钟首球概率
   - 领先后继续进球的能力（二次进攻效率）
   - 对低位防守的破解能力
3. **比赛打开后的进球加速度**（0-1之后是否容易变成2-0、3-0）
4. **体能与赛程密度对下半场的影响**
5. **定位球转化率**（尤其在僵持场景）

### 2.2 次优先变量
- 门将扑救率与低级失误频率
- 替补席冲击力（60分钟后换人效果）
- 主客场进球分布差异

---

## 3. 比分预测优化路径

1. **先判断比赛是否容易「打开」**  
   （早进球概率高 → 大比分权重上升）

2. **区分单边碾压 vs 对攻**  
   单边碾压时，允许3-0、4-0、甚至更高比分进入前三

3. **引入「进球加速度」检查**  
   强队领先后是否具备持续压制能力

4. **结合伤停结构**  
   对手中后场结构型伤停 + 强队状态好 = 大比分概率显著上调

---

## 4. 样本反馈 + 动态调整机制（正式写入）

### 4.1 样本记录要求（每场必须）
- 伤停位置与是否结构型
- 预测方向 / 实际结果
- 预测比分 vs 实际比分（幅度偏差）
- 比赛性质（联赛/杯赛/首回合/次回合）
- 是否出现早进球 / 比赛打开
- 强队兑现率是否达标

### 4.2 动态调整规则
- 样本数量门槛：同类场景至少15–20场才启动调整
- 调整对象：
  - 结构型伤停的降级力度
  - 大比分权重
  - 早进球后的加速度系数
- 机器学习定位：只提供「动态建议」，最终决策仍由交叉研判 + 剧本决定
- 设置冷却期，防止被短期冷门带偏

### 4.3 闭环流程
预测 → 赛后完整记录 → 样本库更新 → 动态参数微调 → 下一次预测使用新参数
