# CAT-X 每日分析工作流程（自动迭代版）

## 目标
每天推演的比赛分析，统一按日期存档，便于长期回溯、复盘与权重自动调整。
系统持续根据赛后结果自我迭代，无需每次人工确认。

## 标准流程

1. **接收比赛数据**
   - 用户提供截图 / 文字 / 链接
   - 补充公开信息（赔率、伤停、近期战绩、xG等）

2. **执行 11 步 CAT-X 分析**
   - 严格按模板完成真实性 → 盘口 → 市场 → 价值 → DNA → 风险 → 逆向 → 剧本 → 玩法 → PASS → 可信度

3. **存档规范**
   - 路径：`analyses/YYYY-MM-DD/主队_vs_客队.md`
   - 文件名使用英文队名或拼音，避免空格和特殊符号
   - 同一天多场比赛放在同一日期文件夹下

4. **更新索引**
   - 在根目录 `README.md` 中追加当日分析列表

5. **赛后复盘（强制自动）**
   - 比赛结束后自动追加 `_Review.md` 复盘文件
   - 对比预测与实际结果
   - 记录偏差并触发权重调整

## 系统迭代规则（2026-07-28 更新）

### 1. 弱旅客场崩溃权重
- 对近5个客场胜率 < 20% 的球队，额外下调其「守平概率」
- 提高主队大胜（赢2球及以上）权重
- 目的：减少「预测赢2球、实际赢4球」的低估情况

### 2. 主场打弱旅的进攻方差修正
- 引入「主场对阵积分榜后1/3球队」的历史大胜频率作为修正项
- 让 2-0 / 3-0 / 4-0 的概率分布更合理

### 3. 比分预测降级策略
- 精确比分降为次要输出
- 优先输出「胜分差区间」（赢1球 / 赢2球+ / 平局区间）
- 降低用户对精确比分的预期误差

### 4. xG 与实际转化率跟踪
- 赛后强制对比赛前预估 xG 与实际进球
- 积累「效率偏差」数据库，长期修正进攻效率判断

### 5. 联赛特性强化
- 挪超：主场优势 + 客场崩盘特性单独建权重表
- 瑞超：前五争夺 + 伤停情况下平局权重上调
- 其他联赛按实际表现持续独立校准

### 6. 自动迭代机制
- 每次赛后复盘后，系统自动记录偏差类型
- 达到一定样本后自动微调对应权重
- 无需每次向用户确认，直接更新 workflow 与后续分析逻辑
