# CAT-X 每日分析工作流程

## 目标
每天推演的比赛分析，统一按日期存档，便于长期回溯、复盘与权重调整。

## 标准流程

1. **接收比赛数据**
   - 用户提供截图 / 文字 / 链接
   - 补充公开信息（赔率、伤停、近期战绩等）

2. **执行 11 步 CAT-X 分析**
   - 严格按模板完成真实性 → 盘口 → 市场 → 价值 → DNA → 风险 → 逆向 → 剧本 → 玩法 → PASS → 可信度

3. **存档规范**
   - 路径：`analyses/YYYY-MM-DD/主队_vs_客队.md`
   - 文件名使用英文队名或拼音，避免空格和特殊符号
   - 同一天多场比赛放在同一日期文件夹下

4. **更新索引**
   - 在根目录 `README.md` 中追加当日分析列表

5. **赛后复盘（可选）**
   - 比赛结束后可追加「赛后复盘」章节
   - 对比预测与实际结果，调整后续权重

## 命名示例
```
analyses/
├── 2026-07-28/
│   ├── KuPS_vs_Sabah.md
│   └── Hearts_vs_Sturm_Graz.md
├── 2026-07-29/
│   └── TeamA_vs_TeamB.md
```

## 权限与自动化
- 当前已具备 Grok 直接写入权限
- 后续可扩展 GitHub Actions 做定时备份或自动生成索引
