# CAT CORE FINAL 2.0｜最终锁定规则（2026-08-13）

**状态**：正式锁定，所有后续推演必须严格执行

---

## 核心原则（最高优先级）

**推演之前必须先问：**  
> “这场比赛双方有没有理由按照实力差全力踢出来？”

如果答案是“没有”或“不完全有”，则实力差的权重必须下调，优先进入情境/剧本判断。

---

## 固定 6 层输出结构（强制）

1. **实力层**：双方真实实力差  
2. **信息层**：伤停、首发、赛程、战意、主客场、历史交锋  
3. **盘口层**：欧赔、亚盘、大小球、水位变化  
4. **PSI冲突层**：实力、盘口、市场是否互相矛盾（专门抓“强队很热但盘口不支持大胜”）  
5. **剧本层**：强压制 / 胶着 / 防守战 / 爆冷 / 控制节奏 等  
6. **结果层**：胜平负 → 进球数 → 比分 → 投注价值

**顺序不可颠倒**：先剧本，再进球结构，最后才落到胜平负和比分。

---

## 硬规则（自动触发）

任何一场出现以下组合时，**自动进入冷门复核**：  
- 热门强队  
- 盘口退让（水位向冷门方向移动）  
- 小球降盘/降水  
- 市场高度集中  

触发后必须：  
- 重新评估平局与冷门概率  
- 高信心至少降一级  
- 比分池必须包含平局或冷门选项  

（专门针对帕梅拉斯 1-1 这类比赛）

---

## 样本积累与复盘要求

连续使用真实赛果复盘，统计：  
- 胜平负命中率  
- 比分命中率  
- 冷门识别率  
- PSI高风险场命中率  
- 进球结构偏差  

达到一定样本后再进一步调参。
