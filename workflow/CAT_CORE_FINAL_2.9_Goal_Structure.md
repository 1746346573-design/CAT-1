# CAT CORE FINAL 2.9｜进球结构正式规则（运动战 + 定位球拆分）

**生效时间**：2026-08-25  
**状态**：强制执行

---

## 1. 核心计算框架

**主队预期进球 = 主队运动战 xG + 主队定位球 xG**  
**客队预期进球 = 客队运动战 xG + 客队定位球 xG**

总进球环境 = 主队预期 + 客队预期

比分由主客预期进球直接推导，禁止先定方向再凑比分。

---

## 2. 运动战 xG 影响因素

- 基础进攻能力（近期场均进球）
- 主客场效率系数
- 对手防线抗压 / 密集防守削弱
- 己方锋线完整度（伤停位置 + 替补质量）
- 战术匹配（高位压迫 vs 低位防守的转化率）
- 门将质量修正
- 天气对技术型进攻的影响

---

## 3. 定位球 xG 影响因素

- 角球 / 任意球创造能力
- 定位球转化率
- 对手定位球防守能力
- 身高 / 支点优势
- 雨战等天气对定位球权重的提升

---

## 4. 额外必须修正的模块

- 早进球加速度（领先后是否继续扩大比分）
- 升班马 / 弱旅主场能量
- 战意与比赛阶段
- 庄家过热预警（仅微调）

---

## 5. 强制输出格式（每场必须）

主队运动战 xG：  
主队定位球 xG：  
**主队总预期进球**：  

客队运动战 xG：  
客队定位球 xG：  
**客队总预期进球**：  

**总进球环境**：  

然后才输出：  
胜负平 / 让球胜负平 / 半全场 / 进球数 / 比分
