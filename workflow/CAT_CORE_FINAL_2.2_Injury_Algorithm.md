# CAT CORE FINAL 2.2｜伤停权重算法（正式版）

**原则**：拒绝死板固定权重，采用「位置基础分 + 动态系数」的弹性结构。

---

## 1. 核心设计思想

- **不使用纯固定数字权重**（避免死板）
- 采用「位置基础影响力」+「实时系数」的组合
- 最终是否降级，由**交叉研判**决定，而不是单一分数

---

## 2. 位置基础影响力（参考区间，非死值）

| 位置 | 基础影响力区间 | 说明 |
|------|----------------|------|
| 主力门将 | 极高 | 直接影响稳定性 |
| 中卫 | 高 | 结构核心 |
| 后腰 / 防守型中场 | 高 | 出球与保护 |
| 中锋 / 绝对核心前锋 | 高 | 终结与支点 |
| 攻击型中场 / 前腰 | 中高 | 创造 |
| 边锋 / 边卫 | 中 | 宽度与往返 |
| 轮换球员 | 低 | 影响有限 |

---

## 3. 动态系数（关键弹性部分）

最终影响 = 位置基础影响力 × 以下系数的综合判断：

1. **球员重要度**（队内地位、是否不可替代）
2. **替补质量**（有没有同级别替代者）
3. **体系依赖度**（该球员在战术中的核心程度）
4. **叠加效应**（是否与其他伤停形成结构型缺口）

### 结构型伤停（优先判断）
出现以下情况时，直接触发强制关注，而不是简单加减分：
- 中卫 + 后腰同时缺阵
- 锋线绝对核心缺阵且无同级别替补
- 门将主力缺阵
- 同一条线（后防/中场/锋线）多人同时缺阵

---

## 4. 实战使用方式（避免死板）

1. 先列出本场所有伤停球员的位置与角色
2. 判断是否构成「结构型伤停」
3. 评估替补质量与体系完整度
4. 将伤停影响放入交叉研判（与实力差、比赛目的、兑现率一起看）
5. 最终由剧本和交叉验证决定是否降级信心或调整比分幅度

**禁止**：用固定数字直接乘算出“胜率下降X%”这种机械做法。

---

## 5. 与整体模型的关系

伤停算法是「球队本体层」的重要输入，但不是最终决策者。  
最终决策仍遵循：

核心问题 → 本体（含伤停）→ 状态 → 比赛目的 → 战术匹配 → 脚本 → 进球模型 → 交叉研判确认
