# CAT CORE FINAL 3.0｜扫盘数据融合规则（正式锁定）

**生效时间**：2026-11-01  
**状态**：强制执行

---

## 1. 核心工作流变更

用户将主动提供「扫盘分析数据」（欧赔/亚盘/资金分布/水位变化/庄家态度等）。

模型必须：
1. 以扫盘数据为重要输入层
2. 与球队基本面、技战术、伤停、主客场效率、战意、天气等交叉验证
3. 输出完整结果：胜负平、让球胜负平、半全场、进球数（单一数字0-7+）、比分
4. 每日赛后核对真实赛果
5. 记录本次扫盘数据的优点与缺点（哪些信号有效、哪些误导）

---

## 2. 推演强制顺序

1. 接收并解析用户提供的扫盘分析数据
2. 核心问题：双方有没有理由按实力差全力踢？
3. 球队本体（伤停位置+替补质量、新援、轮换）
4. 主客场量化效率 + 战术匹配
5. 扫盘数据交叉验证（资金集中是否过热？水位变化是否支持基本面？）
6. 运动战 xG + 定位球 xG → 主队/客队预期进球 → 总进球（单一数字）
7. 最终输出：胜负平 / 让球胜负平 / 半全场 / 进球数 / 比分

---

## 3. 每日复盘强制内容

每场结束后必须记录：
- 预测 vs 实际（全维度：胜负平、让球、半全场、进球数、比分）
- 扫盘数据优点：哪些信号正确指引了方向/比分
- 扫盘数据缺点：哪些信号误导、过热或与基本面冲突
- 模型自身失误点与下次调整

样本持续追加至 `database/Sample_Library_Core.md`
