# CAT CORE FINAL 2.1｜择优升级记录（2026-08-20）

**来源**：6场真实赛后复盘（安养-济州、马竞-马拉加、凯尔特人-LASK、波特诺-帕尔梅拉斯、奈梅亨-博德、布拉迪斯拉发-采列）

**状态**：已择优融入正式模型

## 1. 核心保留与强化

- 继续严格执行：先问“双方有没有理由按实力差全力踢出来？”
- 比赛目的 / 比赛阶段引擎（首回合/次回合/淘汰赛比分）继续作为高优先级
- PSI盘口冲突指数继续保留

---

## 2. 新增 / 强化模块（择优）

### 2.1 伤停分析升级
**旧**：只看伤停人数  
**新**：**伤停位置 + 替补体系质量**

- 锋线核心缺阵 → 必须下调大胜、穿深盘、4+球概率
- 强队锋线缺人 ≠ 不能赢，但进攻流畅度和大比分概率显著下降
- 必须同时评估替补球员质量与体系完整度

### 2.2 进攻转化率拆分
**机会制造** 与 **机会转化** 必须分开判断。

- 不能因为客队有反击能力，就自动推导主队会丢球
- 必须额外判断：该队能否把制造的机会真正转化为进球
- 新增场景标签：进攻转化率高低

### 2.3 强队兑现率（新增核心变量）
不能只计算纸面实力差，必须判断实力差是否转化为：
- 射门优势
- 禁区触球
- 高位压迫
- 定位球优势
- 首球概率
- 持续压制能力

如果只是“纸面实力强”而没有形成比赛控制力 → 主胜概率高 ≠ 穿盘概率高 ≠ 大胜概率高。

### 2.4 大球拆分（必须执行）
大球 ≠ 双方进球。必须拆成以下类型：
- 主队单边大球
- 客队单边大球
- 双方对攻
- 强队碾压型大球
- 后程开放型大球

（凯尔特人3-0 LASK 是典型“高进球环境但非双向对攻”样本）

---

## 3. 推荐新层级结构（2.1版）

1. **球队本体**：实力 → 阵容 → 主力伤停 → 伤停位置 → 替补质量 → 体系完整度
2. **状态**：近期状态 → 主客场 → 攻防效率 → 体能 → 赛程密度 → 轮换
3. **比赛目的**：联赛积分 / 杯赛淘汰 / 欧战首回合 / 次回合 / 系列赛比分 / 必须赢或可接受平局
4. **战术匹配**：谁控球 → 谁压迫 → 谁反击 → 谁退防 → 阵型变化
5. **比赛脚本**：0-30 → 30-60 → 60-75 → 75-90（首球 → 落后方反应 → 开放程度 → 第二球 → 最终比分）
6. **进球模型**：0/1/2/3/4/5/6/7+ 及具体比分（结合单边/双边大球拆分）
7. **市场**：欧赔/亚盘/大小球/资金/盘口变化 → 仅作异常校验，不决定方向
