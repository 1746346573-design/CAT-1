## 2. 严重打脸样本（强制回看）

### 赫尔城 2-0 曼联（英超）
- 预测：客胜 0-2/0-3
- 实际：2-0 主胜
- 打脸原因：
  - 低估升班马主场能量
  - 完全没评估「密集防守 + 优秀门将」对强队的克制
  - 曼联物理对抗与终结效率崩溃
- 强制调整：升班马主场首战 + 密集防守时，强队客胜必须降级

### 秋田 3-0 甲府（日乙）
- 预测：平/客胜
- 实际：3-0 主胜
- 打脸原因：
  - 过度放大主队7人伤停
  - 没评估对手进攻能力极弱
  - 雨战变量缺失
- 强制调整：对手进攻极弱时，即使己方人员不整，主胜权重仍可保留

### 001 博洛尼亚 0-1 拉齐奥
- 预测：平/主胜 1-1/1-0
- 实际：0-1
- 打脸原因：高估主队基本盘，低估客队残阵反击效率
- 调整：意甲新帅首秀 + 客队防线轮换，客胜/平权重上调

### 004 奥萨苏纳 0-0 莱万特
- 预测：主胜 1-0
- 实际：0-0
- 打脸原因：赛季初主队谨慎 + 客队惨败后收缩，平局剧本被忽略
- 调整：西甲赛季初接近盘口，平局权重提高

### 006 罗马 4-0 佛罗伦萨
- 预测：1-0/2-1
- 实际：4-0
- 打脸原因：比分幅度严重不足
- 调整：强队主场对有伤停对手，必须允许3-0、4-0进入前二

### 008 富勒姆 2-3 切尔西
- 预测：0-2/1-2
- 实际：2-3
- 打脸原因：低估主队进球能力，半全场与比分偏差
- 调整：英超德比即使客队强，也要给主队进球空间

## 4. 使用规则

以后每场推演前：
1. 先判断属于哪类场景
2. 调出对应成功/打脸样本
3. 再计算主队/客队预期进球
4. 最后推导比分

样本库会持续追加。
